Merci d'avoir installé Guestbook !

Release : {{ .Release.Name }}
Namespace : {{ .Release.Namespace }}
Environnement : {{ .Values.commonLabels.environment }}

Pour vérifier les ressources :
  kubectl get pods -n {{ .Release.Namespace }}
  kubectl get services -n {{ .Release.Namespace }}

Pour accéder au frontend :

{{- if eq .Values.frontend.service.type "LoadBalancer" }}
  Service de type LoadBalancer :
  kubectl get svc {{ .Values.frontend.service.name }} -n {{ .Release.Namespace }}

  Sur Minikube, lance également :
  minikube tunnel
{{- else }}
  Service de type ClusterIP :
  kubectl port-forward svc/{{ .Values.frontend.service.name }} {{ .Values.frontend.service.port }}:{{ .Values.frontend.service.targetPort }} -n {{ .Release.Namespace }}

  Puis ouvre http://localhost:{{ .Values.frontend.service.port }}
{{- end }}
